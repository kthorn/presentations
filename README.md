# presentations

Talk materials. Each talk lives in its own directory.

- `bof-2026-10/` — Agentic Engineering BoF (Prime Radiant, SF, 2026-10-14): three slides.
- `docs/` — design notes and literature review for the BoF talk.
- `reports/`, `research_notes/` — background research on foundation models vs. LLM + DSL + checker.
- `computing-poster/` — computing power over time, supercomputers vs. home machines. `python3 make_chart.py` writes `chart.png` (landscape poster), `chart-mobile.png` (4:5, for social media) and `table.md` from `data/`.
